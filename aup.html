可接受使用政策

最后更新：2026年8月14日 · 生效日期：2026年8月14日

We Apps（以下简称"平台"、"我们"）致力于提供安全、合法、负责任的 AI 内容生成服务。本可接受使用政策（"本政策"）适用于所有通过我们的产品（包括 We Quiz、We Learn、We Review）生成、发布、传播或存储的内容，并规定了我们的内容标准、审核机制、举报流程及违规处置方式。所有使用本平台的用户均须遵守本政策。

一、适用范围

本政策适用于以下所有内容形式：

  • 文本：AI 生成的题目、题干、选项、答案及解析等。
  • 用户输入：用户提交的学习材料（文档、文本）及提示词、指令。
  • 图片转文本：用户上传的图片（如扫描件）经文字识别后转换的文本。

本服务不生成图像、音频或视频内容。

二、内容标准与禁止类别

平台明确禁止利用本服务生成以下六类内容：

  • 色情 / NSFW 内容。
  • 暴力 / 血腥内容。
  • 仇恨言论。
  • 儿童不安全内容（CSAM）。
  • 深度伪造 / 冒充他人（Deepfake）。
  • 侵犯版权 / 商标的内容。

后续条款对上述类别及其他违规行为作出细分。

（一）绝对禁止——零容忍

以下内容一经发现立即处置，并保留向主管机关报告的权利：

  • 儿童性剥削内容（CSAM）或任何涉及未成年人的性相关内容。
  • 宣扬或协助恐怖主义、极端主义及大规模暴力的内容。
  • 大规模杀伤性武器制造技术指导。
  • 煽动种族灭绝或民族仇恨的内容。
  • 针对真实个人、未经同意的深度伪造（Deepfake）性内容。
  • 其他目标市场法律法规所禁止的内容，包括任何危害未成年人身心健康的内容。本服务面向学习者，可能有未成年用户使用，我们对其适用更严格的内容标准。

（二）严格限制——需经审核

  • 暴力内容：须有明确的教育或创作情境（如历史、医学类学习材料中的正常内容）。
  • 医疗/法律/金融内容：仅限学习与教育用途，不得作为专业建议使用，须符合所在地监管要求。

本服务不提供、也不允许任何成人 / NSFW 内容，不设此类例外。

（三）一般禁止行为

  • 生成或传播虚假信息、谣言。
  • 冒充真实个人、品牌或机构。
  • 侵犯知识产权、肖像权或隐私权（包括上传无权使用的他人资料作为学习材料）。
  • 以 AI 内容欺骗用户、声称系人工创作。
  • 批量生成垃圾或欺诈性内容。
  • 用于绕过平台安全机制的越狱（Jailbreak）提示词。

三、内容审核机制

平台采用"自动审核 + 人工复核 + 定期抽检"的多层次审核体系。

（一）自动审核（实时）

所有请求及生成内容实时经安全过滤器扫描。

  • 输入过滤：用户上传的学习材料与提示词在进入生成模型前，经内容安全服务扫描，仅当判定通过时才继续生成。
  • 输出过滤：AI 生成的题目在保存与展示前，经内容安全扫描，未通过的内容不会入库或展示。
  • 使用模式分析：通过调用限额与频率限制监测异常的调用行为。
  • 使用的安全服务：Waffo Pancake 内容安全扫描（Content Safety Scan）。该检查无状态，返回后不留存原文。

（二）人工复核

  • 自动标记的内容进入人工复核队列。
  • 用户举报的内容由平台内容安全负责人核查。
  • 复核人员须完成内容安全培训，并对复核内容保密。

（三）定期抽检

  • 平台对生成内容进行不定期随机抽样审查，并持续评估自动审核系统的表现。

（四）内容分级标准

级别 描述 审核 处置
L1 严重 儿童安全、恐怖主义 自动拦截 + 人工确认 立即封禁 + 上报
L2 高风险 严重违规内容 自动标记 + 优先复核 下架 + 暂停账户
L3 中风险 一般违规 人工复核 警告 + 移除
L4 低风险 轻微违规 举报触发 警告 + 要求修改

四、举报机制

（一）举报适用情形

  • 违反本政策内容标准的内容或行为。
  • 涉及儿童安全、恐怖主义等严重违规。
  • 发现 AI 冒充或侵犯自身权利的行为。

（二）举报原则

  • 保密性：对举报人身份严格保密。
  • 中立性：所有举报经独立、客观审查。
  • 防止滥用：恶意或虚假举报将被记录并处理。

五、举报入口

专用举报与客服邮箱：support@weapps.dns-dynamic.net（真人值守）

六、处理时效

违规举报按严重程度分级、优先处理：

  • L1 严重违规：收到后立即处理；涉嫌违法的，向主管机关报告。
  • L2–L4：按风险等级依次尽快处理。

如需延长处理时间，我们将主动通知举报人并说明原因。处理流程：收到举报 → 初步分级（L1–L4）→ 内容审核（自动 + 人工）→ 处置决策 → 执行处置 → 结果通知。

七、违规处置措施

处置 措施 适用情形
1. 内容警告 书面警告，要求删除或修改 首次轻微违规
2. 内容下架 移除违规内容（生成的题目、上传的材料） 确认的 L3–L4
3. 功能限制 降低 AI 调用限额或关闭 AI 功能 多次轻微或单次 L3
4. 账户暂停 临时暂停，待复核 L2 或累计违规
5. 永久封禁 永久终止访问权限 L1 或多次 L2
6. 法律追责 向执法机构报告，配合调查 涉嫌违法的 L1

八、申诉机制

如对处置结果有异议，可在收到通知后 30 日内提交申诉：

  • 申诉渠道：support@weapps.dns-dynamic.net
  • 复核方式：申诉案件将对照本政策，对全部材料与初次处置依据进行重新审查，独立于初次处置记录存档；必要时征询外部专业顾问意见。

九、透明度与政策变更

本政策发生重大变更时，将通过网站公告或产品内通知提前告知；继续使用本服务即视为接受更新后的政策。
